**#**Project Description:
We will use a lightweight source and free LLM to create a sandbox environment that allows a user to be taught about prompt injection. The user will have to go through several levels, that explore various examples of prompt injection.
-> Of course, for security reasons the AI will not actually have major access to system resources, however, we will attempt to emulate this exact behavior
-> Note that to move on to the next level, the user will have to submit a ‘flag,’ found by exploiting the AI
